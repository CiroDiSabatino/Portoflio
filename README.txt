CIRO DI SABATINO — MOBILE GAME ART PORTFOLIO
===========================================

WHAT'S INSIDE
- index.html       Main responsive website (English)
- styles.css       Visual styles and mobile layout
- script.js        Portfolio filters and fullscreen image viewer
- assets/          Optimized portfolio images and graphic assets
- docs/            Original CV and both complete PDF portfolios
- .nojekyll        GitHub Pages compatibility file

PREVIEW IT OFFLINE
1. Extract this ZIP to a folder.
2. Double-click index.html to open it in Chrome, Edge, Safari or Firefox.
3. Try Concept Art / Game UI filters and tap the small images to enlarge them.
4. The CV and both full portfolios are included and can be viewed offline.

PUBLISH WITH GITHUB PAGES
1. Log into GitHub and create a NEW PUBLIC repository, for example 'game-art-portfolio'.
2. Upload the CONTENTS of this folder to the repository ROOT. Keep the folder
   structure: index.html, styles.css, script.js, assets/, docs/, .nojekyll.
3. In that repository go to Settings > Pages.
4. Under Build and deployment, Source = Deploy from a branch.
5. Choose branch 'main' and folder '/ (root)' then Save.
6. Copy the public website URL displayed by GitHub Pages after publication.
7. Open that URL on a phone and test images, links and PDF downloads.

QR CODE
A QR code for the new mini-site should only be created AFTER it has a
working public URL. Send the published URL to ChatGPT to generate a scannable
PNG/SVG/PDF QR code for event cards. Do not print a QR code with a temporary
or guessed URL. Test it on iPhone and Android before mass printing.

VISUAL + CONTENT NOTES
- The visuals are selected from the author's own three uploaded PDF documents.
- Copy is in English for international events and recruiters.
- All graphics and document links are local; no external libraries, trackers,
  cookies or external fonts are required. LinkedIn and ArtStation links do
  open their external websites.
- Downloadable CV contains personal contact details; when publicly hosting
  this site, those details also become publicly available.
- If an employer needs all the work, use the two 'Full Portfolio' links.
- To change copy or projects later, edit index.html; adding new images may
  also require updating the assets folder.
